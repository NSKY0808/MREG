# Changelog

## Unreleased — 2026-10-04

Renamed the project to MREG (Model Release Evidence Gate), including the Python
package, CLI command, CI workflow, documentation, and package metadata. Use
`import mreg` and the `mreg` command in place of the previous names.

## 0.1.0 — 2026-10-03

Initial local MVP: binary classification evidence/policy contracts, deterministic
checks, JSON/Markdown/bundle output, replay, optional paired evaluation and experimental
bootstrap, regression tests, synthetic examples, and CI integration template.

No hosted service, registry adapter, assistant, or deployment integration is included.
